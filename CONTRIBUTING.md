# Contributing to Rozana Khaata

## How to Contribute

### 💡 Feature Suggestions
- Open an issue on GitHub
- Describe the feature
- Explain why it's useful

### 🐛 Bug Reports
- Open an issue with "Bug" label
- Describe what happened
- Steps to reproduce

### 📝 Documentation
- Suggest improvements
- Fix typos
- Add examples

## Code of Conduct
- Be respectful
- Help others learn
- Provide constructive feedback

Thank you! 🚀
